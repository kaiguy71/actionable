Create a framework for a Fabric Mod for Minecraft 26.3 that will allow a user to write a command in chat, such as '/action Build a 30x30 house made out of light-colored stone blocks', 
which takes that input and prompts a locally running Gemma LLM instance to plan the execution of that task. The LLM will then be able to automate inputs back into the game using baritone commands, 
(https://github.com/cabaletta/baritone/tree/26.3). 

The LLM will also needs access to a very basic synopsis of its surroundings, for instance, if there is a mob that begins to attack it, it should be able to respond on its own to the obstacle 
keeping it from completing the original task. There should also be a disable switch bound to CTRL+` (grave).

For example, if the user prompts the LLM using the /action command to "Build a 30x30 house made out of light-colored stone blocks", it should 
1. Determine what the light colored stone blocks it should target are, 
2. Analyze the surroundings for what kinds of stone blocks would be available within a reasonable amount of time, 
3. Ensure the player has the correct tools for the job, if not, automatically be able to source those tools without further prompting, and 
4. return to the original prompt location, decide where the house would be the most appealing, and complete construction of the exterior.
While those exact steps may or may not occur as according to the LLM's decision making skills, the idea is that we can equip it with enough tooling to be able to do 
    all of those things (and more things in the future) with 1. As few tokens as is feasible, and 2. with great enough direct control to be able to make adjustments on the
    fly when running on consumer grade hardware (such as an RTX 3070)
